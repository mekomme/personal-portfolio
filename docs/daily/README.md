# יומן יומי

רשומה אחת לכל יום עבודה על האתר, בקובץ `YYYY-MM-DD.md`.
הרשומה נכתבת בסוף היום ונדחפת יחד עם הקוד של אותו יום.

## מבנה רשומה

```markdown
# YYYY-MM-DD

## מה נעשה
- שינוי אחד בשורה, בלשון עבר.

## קומיטים
- `<sha קצר>` — כותרת הקומיט

## פתוח למחר
- מה נשאר.
```

כדי לראות את הקומיטים של יום מסוים:

```sh
git log --oneline --since=2026-08-28 --until=2026-08-29
```

## קשר למקטע "עדכונים" באתר

היומן כאן הוא המלא והפנימי. מקטע `#updates` ב-`index.html` הוא התקציר
שמוצג למבקרים — לא כל רשומה כאן מגיעה לאתר, אבל כל עדכון שמופיע באתר
צריך להיות מגובה ברשומה כאן.
