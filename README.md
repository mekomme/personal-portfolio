# אתר תדמית אישי — תחביב ההימורים

אתר תדמית אישי בעברית (RTL) בעמוד אחד, שמציג את בעל האתר ואת תחביב ההימורים
שלו — פוקר, בלאק ג'ק, רולטה והימורי ספורט — כמאמר מגזין מעוצב.

> זהו אתר תדמית אישי בלבד. **אין** בו משחק בכסף אמיתי, הרשמה, יחסי הימור או
> קישור למפעילי הימורים. התוכן מיועד לגילאי 18+.

## תצוגה

פותחים את `index.html` בדפדפן. אין build, אין תלויות, אין שרת.

```sh
start index.html      # Windows
```

## מבנה

| מקטע | תוכן |
|---|---|
| Hero | שם, תגלית "בין מתמטיקה למזל", שני CTA |
| סטטיסטיקות | שנות משחק · טורנירים · שולחנות · משחק אהוב |
| אודות | ביו + שלושה עקרונות: משמעת, הסתברות, קור רוח |
| המשחקים שלי | רשת כרטיסים לפי משחק, עם תגית רמה |
| ציר זמן | אבני דרך אישיות בתחביב |
| רגעים | גלריית תצלומים |
| פילוסופיה | ציטוט רחב על סיכון ושליטה עצמית |
| משחק אחראי | הערה על משחק בגבולות, 18+ |
| צור קשר | פרטים + טופס |

## עיצוב

פלטה כהה בסגנון טרקלין: פחם כמעט־שחור, ירוק אמרלד (לבד קזינו) וזהב.
מוטיבים של סמלי קלפים (♠ ♥ ♦ ♣) כפרטים דקורטיביים עדינים בלבד.
כותרות serif גדולות מול גוף sans-serif עברי.
